# Project Brief

## What this is

Working notes / memory bank for the **fully integrated software for Ajera**.

The software integrates field operations with Ajera, covering:

- **Logistical measurements** — logistics-side measurement capture.
- **Field survey input data** — full field survey data entry into the system.
- **Bluetooth printer labeling** — on-site label printing via Bluetooth
  printer as part of the field workflow.

## Current Phase

Beta testing of the fully integrated build. See `activeContext.md` for the
current focus and `progress.md` for the running status log.

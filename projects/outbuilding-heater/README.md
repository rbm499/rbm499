# Outbuilding heater: barrel rocket mass heater plans

Rev A, 2026-09-27. Plan set for an 8-inch J-tube rocket mass heater under a
55-gallon drum, venting through a sand-and-pebble sleeping bench, for the
outbuilding Ryan will be staying in.

- **Live page (private):** https://claude.ai/artifact/8E3KdMG3iJ64qTJm3UmEfz
- **Page source:** `barrel-rocket-mass-heater.html` (the published file).
- **Generator:** `src/`. All five sheets are drawn from the `G` dict in
  `src/figures.py`, so a dimension change there moves every view. Rebuild with
  `python3 src/build.py barrel-rocket-mass-heater.html` from this folder.

## Open before building (Class 3: Ryan decides)

1. Washington install rule. Ecology and PSCAA both state that installing an
   uncertified wood stove is illegal in WA; ORCAA lists installation of an
   uncertified device by a private citizen as a violation. INFERRED: this
   heater is an uncertified device with no certification path.
2. Permit, occupancy and insurance for a site-built heater in a slept-in outbuilding.
3. Floor: the bench alone is about 2,800 to 3,000 lb (INFERRED); slab on grade only.
4. CO and smoke alarms before the first fire.
5. What the drum held (OSHA 1910.252(a)(3)(i) before any cutting).
6. Pipe diameter and whether it is galvanized.
7. Room clearances (NFPA 211 unlisted-stove values, from secondary sources).
8. Roof penetration with listed chimney parts.

## Not in record

County the outbuilding is in (PSCAA for King, ORCAA for Mason); building size
and insulation; floor type at the heater spot; pipe diameter and coating; the
drum's prior contents; what the "packing pebbles" are.

## Research limits

This session's network blocked direct page loads, so all sources were read as
search-engine excerpts; the page's source record lists every link. Design
numbers come mostly from practitioner sources (Wisner, Evans and Jackson, via
permies.com), not tested standards. The 6-inch column is reference only; the
drum geometry changes the 6-inch tunnel and riser, so redraw before building
at 6 inches.

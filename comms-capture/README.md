# comms-capture

Captures the client texts that arrive on Michael's phone, screens out anything private, files the business
ones into the job's folder, asks Ryan only when a job number can't be worked out, and makes sure no client
who needs an answer is left waiting.

* `android/` — the phone agent (Kotlin). `core` is tested here (241 tests); the whole app builds in CI (`.github/workflows/comms-capture-android.yml` → artifact `commscap-debug-apk`). Never run on a device yet.
* `server/` — the office service (Python/FastAPI): screening, job matching, filing, reply clock, health, review page.
* `shared/vectors/` — test vectors both sides must pass (generated by `tools/gen_vectors.py`).
* `docs/WIRE_CONTRACT.md` — the phone ⇄ office interface. `docs/DESIGN.md` — decisions, failsafes, what is verified.
* `ios/` — what to do if Michael's phone is an iPhone (not needed: it is a Samsung S25). `docs/FIRST_INSTALL.md` — first install and first-run checklist.

## Try it now (synthetic data, no AI, nothing leaves the machine)

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -e "server[dev]"
python -m pytest server -q
python tools/demo.py 8799        # open http://127.0.0.1:8799/ui   token: demo
```

## Run it for real

```bash
pip install -e server
commscap new-secret --device michael-phone-1 --url https://YOUR-HOST   # prints the secret + the phone setup string
export COMMSCAP_DEVICE_SECRETS="michael-phone-1:<secret>"
export COMMSCAP_UI_TOKEN="<long random string>"
export COMMSCAP_JOBS_ROOT="C:\\Users\\<user>\\Desktop\\Job sites"      # the folder that holds "26-3310 1026" etc.
export COMMSCAP_REGISTER="path\\to\\JOB_PIPELINE.json"                  # client numbers + job list
export ANTHROPIC_API_KEY="..."                                          # screening; without it unknown numbers wait unseen
export COMMSCAP_ALERT_EMAIL_TO="ryan@example.com" COMMSCAP_SMTP_HOST=... # alerts also always land in data/outbox/
commscap serve --host 127.0.0.1 --port 8787
```

Optional: `COMMSCAP_ALERT_EACH_MESSAGE=on` raises one alert (who, which job, topic - never the text) for every business text in or out;
`COMMSCAP_FEED_EXPORT=<path>\feed.json` also writes the live conversation feed to a file (e.g. in a Drive-synced folder) for another viewer.

Put it behind HTTPS (reverse proxy or tunnel) — the phone talks to it over the internet and the review page
uses a bearer token. The review page (`/ui`) opens on a **live conversation view** (business texts in and out, newest first, auto-refreshing, with an optional
"alert me on this device" notification while the page is open). In Chrome on Android, menu > **Add to Home screen** gives it an app icon
(not yet tried on the S25). `commscap tick` runs one maintenance pass if you prefer a scheduler to the built-in loop.
`COMMSCAP_MODEL` defaults to `claude-opus-5-5`; a smaller model is a one-line change.
